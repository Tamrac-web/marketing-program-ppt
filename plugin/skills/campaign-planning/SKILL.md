# 医疗健康行业推广策划框架

## 一、推广策略框架 OAMCM

OAMCM 即 Objective-Audience-Message-Channel-Measurement，是本框架的顶层逻辑。

### 1.1 目标（Objective）

市场导入期聚焦**认知构建**，不做大众教育，做精准支点。

核心原则：
- 不追求全民知晓，追求关键决策者认知翻转
- 不做广覆盖低转化的患者端教育，做窄圈层高浓度的医生端渗透
- 第一年目标不是销量，是"品类=品牌"的心智锚定
- 成功标志：目标科室主任提到品类时，第一反应是你

阶段目标拆解：
- M1-M3：核心 KOL 认知率 >80%，首批合作签约完成
- M4-M6：KOC 层活跃率 >60%，央视首播落地
- M7-M9：种子层月均产出稳定，搜索指数环比增长 >30%
- M10-M12：品类搜索词自然流量占比 >50%，续约率 >70%

### 1.2 受众（Audience）

核心受众不是患者，是**医生**。患者教育是医生完成转化后的下游动作。

三层分级：
- **KOL（Key Opinion Leader）**：全国头部专家 5 位，决定行业风向
- **KOC（Key Opinion Consumer）**：省/市核心医生 15 位，决定区域扩散速度
- **种子医生（Seed Doctor）**：地市骨干 30 位，决定终端转化密度

受众画像关键维度：
- 职级：主任/副主任/主治
- 专科：核心术式经验、年手术量
- 影响力：学术发表、协会职务、自媒体粉丝量
- 配合度：过往合作响应速度、内容产出意愿

### 1.3 信息层级（Message）

四层递进，每层解决一个认知障碍：

| 层级 | 核心问题 | 信息内容 | 载体 |
|------|----------|----------|------|
| 第一层 | 为什么关注？ | 临床痛点 + 趋势数据 + 政策信号 | 学术论文/政策解读 |
| 第二层 | 方案是什么？ | 技术原理 + 适应症 + 循证证据 | 专家讲座/白皮书 |
| 第三层 | 为什么选你？ | 差异化优势 + 真实案例 + 安全数据 | 央视专题/手术直播 |
| 第四层 | 下一步做什么？ | 合作路径 + 培训支持 + 利益设计 | 1v1 拜访/科室会 |

信息设计原则：
- 先讲痛点再讲方案，先讲证据再讲品牌
- KOL 层侧重第一、二层（学术认同），种子层侧重第三、四层（操作落地）
- 所有信息必须有循证支撑，不做无数据的情感营销

### 1.4 渠道（Channel）

三属性叠加模型：**权威 x 高频 x 纵深**。

单一渠道无法同时满足三个属性，必须组合：
- 权威（央视/党媒）：解决"敢不敢用"
- 高频（自媒体）：解决"记不记得住"
- 纵深（学术/科室会）：解决"会不会用"

详见第二章"四层渠道系统"。

### 1.5 衡量（Measurement）

四层漏斗指标体系：

| 漏斗层 | 指标 | 数据来源 | 目标值（年度） |
|--------|------|----------|--------------|
| 曝光 | 总触达人次 | 平台数据后台 | >5000 万次 |
| 认知 | 品牌认知率（目标医生） | 季度调研问卷 | >60% |
| 询问 | 主动咨询/合作意向数 | CRM 系统 | >200 条 |
| 转化 | 实际合作/采购医生数 | 销售系统 | >50 位 |

辅助指标：
- 搜索指数：品牌词+品类词百度/微信指数周环比
- 内容资产：累计优质内容数、长尾流量占比
- NPS（医生端）：推荐意愿净值

## 二、四层渠道系统

### 2.1 权威背书层

| 维度 | 说明 |
|------|------|
| 属性 | 信任 |
| 核心渠道 | 央视（CCTV-1/CCTV-4/CCTV-13/央视频） |
| 解决问题 | 克服三类器械信任壁垒——"这东西靠谱吗？" |
| 代表渠道 | CCTV-1《生活圈》《消费主张》、CCTV-13 新闻直播间、央视频纪录片 |
| 内容形式 | 8-15 分钟专题片、3 分钟新闻报道、30 秒硬广（辅助） |
| 目标人群 | KOL + 医院管理层 + 采购决策者 |
| 预期触达 | 单次专题片 2000-5000 万人次 |
| 单次预算区间 | 80-200 万/次（含制作+媒介） |
| 频次建议 | 全年 2-4 次，集中 Q2/Q3 |

关键执行细节：
- 立项周期 2-3 个月，需提前一个季度启动
- 必须配合"二次传播"——专题片切片投放全网，放大 ROI
- 建议绑定 1 位 KOL 出镜，增强专业背书感
- 硬广单投性价比低，必须专题+硬广组合

### 2.2 高频触达层

| 维度 | 说明 |
|------|------|
| 属性 | 频次 |
| 核心渠道 | 自媒体矩阵（抖音 60% / 视频号 20% / 小红书 15% / 知乎 5%） |
| 解决问题 | 在搜索侧建立长期资产——"搜什么都能找到你" |
| 代表渠道 | 品牌官方号 + KOC 个人号 + 素人患者号 |
| 内容形式 | 60s 短视频/图文科普/直播连麦/长文深度 |
| 目标人群 | KOC + 种子医生 + 潜在患者（被动触达） |
| 预期触达 | 月均 500-1000 万次（矩阵合计） |
| 单次预算区间 | 单条 0.5-5 万（KOC 合作）；月度运营 15-30 万 |
| 频次建议 | 周更 3-5 条/账号，重大节点日更 |

平台策略分拆：
- **抖音（60%）**：流量最大，适合短平快科普、术后案例、医生 IP 打造；算法推荐适合冷启动
- **视频号（20%）**：微信生态闭环，适合医生圈层扩散、私域导流；打开率稳定
- **小红书（15%）**：女性决策者集中，适合术后体验、审美类内容；搜索权重高
- **知乎（5%）**：长尾搜索价值，适合深度技术问答、学术向科普；SEO 效果持久

### 2.3 纵深渗透层

| 维度 | 说明 |
|------|------|
| 属性 | 决策 |
| 核心渠道 | 党媒（人民网/新华网/光明网）+ 行业媒体（健康报/医学界/丁香园） |
| 解决问题 | 影响监管层和采购委员会——"上面有没有定调？" |
| 代表渠道 | 人民网健康频道、新华网科技频道、光明网卫生频道、健康报 |
| 内容形式 | 深度专访（3000-5000 字）、政策解读、专家圆桌、白皮书发布 |
| 目标人群 | 医院管理层 + 卫健委/药监局 + 学术委员会 |
| 预期触达 | 单篇 50-200 万阅读（平台分发）；核心影响 500-1000 位决策者 |
| 单次预算区间 | 5-20 万/篇（含采写+平台推广） |
| 频次建议 | 月度 2-4 篇，配合央视播出节点集中释放 |

执行要点：
- 党媒稿件需 2-4 周审核周期，内容需严格合规
- 建议配合行业会议节点（如中华医学会年会、两会医疗提案）发布
- 深度访谈优先绑定 KOL，增加稿件学术厚度
- 行业媒体（丁香园/医学界）侧重技术深度，面向临床一线

### 2.4 学术推广层

| 维度 | 说明 |
|------|------|
| 属性 | 专业 |
| 核心渠道 | 学术会议 / 科室会 / 手术演示 / Workshop |
| 解决问题 | 同行教育和转介网络——"谁在用？效果怎么样？" |
| 代表渠道 | 全国年会/区域学术沙龙/院内科室会/手术直播平台 |
| 内容形式 | 主题演讲/手术直播/圆桌讨论/临床数据分享 |
| 目标人群 | 全层级医生（KOL 主讲、KOC 参与、种子旁听） |
| 预期触达 | 线下 200-500 人/场；线上直播 5000-2 万人/场 |
| 单次预算区间 | 科室会 2-5 万/场；区域沙龙 10-20 万/场；全国卫星会 50-100 万/场 |
| 频次建议 | 科室会月均 4-8 场；区域沙龙季度 2-3 场；全国会年度 1-2 场 |

执行要点：
- 学术会议是 KOL 核心活跃场景，必须深度参与而非赞助挂名
- 手术演示比 PPT 演讲转化率高 3-5 倍，优先安排
- 线上直播录播二次利用：切片 → 自媒体内容 → 长尾流量
- 科室会是种子医生转化的核心场景，需配合销售团队协同

## 三、KOL/KOC/种子三层体系

### 3.1 Tier 1 KOL（5 位）

**定位**：全国头部专家，行业风向标。

| 维度 | 要求 |
|------|------|
| 职级 | 正高/博导/学科带头人 |
| 学术 | 核心期刊年发表 ≥3 篇，国家级课题在研 |
| 行业影响 | 专委会主委/副主委，全国会议主讲人 |
| 粉丝量 | 全网 ≥50 万（非硬性，学术型可放宽） |

合作模式：
- 央视专题出镜（年 1-2 次）
- 党媒深度专访（季度 1 次）
- 全国学术会议主讲/主持（年 2-3 场）
- 品牌首席顾问/学术委员会主席

年度预算分配：30-50 万/位（含劳务/差旅/学术支持）

### 3.2 Tier 2 KOC（15 位）

**定位**：省/市核心医生，区域扩散引擎。

| 维度 | 要求 |
|------|------|
| 职级 | 副高及以上/科室副主任 |
| 手术量 | 年术式 ≥100 台 |
| 自媒体 | 全网粉丝 ≥5 万，或单平台 ≥3 万 |
| 区域影响 | 省级学会常委/委员 |

合作模式：
- 自媒体周更（≥2 条/周，品牌相关 ≥1 条/周）
- 区域学术沙龙主讲（季度 1-2 场）
- 科室会带教（月度 1-2 场）
- 同行推荐和转介绍

年度预算分配：10-20 万/位（含内容制作费/学术劳务/流量投放）

### 3.3 Tier 3 种子医生（30 位）

**定位**：地市骨干，终端转化和患者教育主力。

| 维度 | 要求 |
|------|------|
| 职级 | 主治及以上 |
| 手术量 | 年术式 ≥50 台 |
| 配合度 | 响应 24h 内，内容产出意愿强 |
| 学习力 | 新技术采纳速度快，愿意参加培训 |

合作模式：
- 病例产出（月 ≥2 例完整病例图文/视频）
- 患者教育内容（术前沟通/术后随访素材）
- 科室会参与/旁听
- 转介绍追踪反馈

年度预算分配：3-8 万/位（含病例费/培训差旅/小额激励）

### 3.4 四维评分模型

总分 100 分，四维各占 25 分：

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 职级 | 25 分 | 正高 25/副高 20/主治 15/住院 10 |
| 专科 | 25 分 | 核心术式经验（年量/年限/难度系数） |
| 影响力 | 25 分 | 学术发表 + 协会职务 + 自媒体粉丝 + 同行引用 |
| 配合度 | 25 分 | 响应速度 + 产出频率 + 内容质量 + 活动参与率 |

### 3.5 动态调整机制

- 评估周期：每季度末评分一次
- 晋升条件：连续两季度总分达到上一层入门线 + 核心指标达标
- 降级条件：单季度配合度 <10 分，或连续两季度总分下降 >15 分
- 退出条件：合规问题/负面事件/主动终止合作
- 新增机制：每季度开放 3-5 个种子名额，优先从活跃用户中选拔

## 四、预算三档模型

### 4.1 分配原则

**4-4-2 结构**：
- 40% 自媒体 + 学术推广（高频触达 + 学术纵深）
- 40% 央视 + 党媒 PR（权威背书 + 纵深渗透）
- 20% 数据合规 + 项目管理（基础设施 + 运营保障）

### 4.2 下档 250 万（起步验证）

**定位**：最小可行推广方案，验证模型跑通。

| 板块 | 预算 | 占比 | 核心动作 |
|------|------|------|----------|
| 央视 | 80 万 | 32% | 1 次专题片 + 2 次新闻报道 |
| 自媒体 | 70 万 | 28% | 5 位 KOC 年度签约 + 基础矩阵运营 |
| 党媒 PR | 40 万 | 16% | 季度 2-3 篇深度 + 节点集中释放 |
| 学术推广 | 30 万 | 12% | 科室会 12 场 + 区域沙龙 2 场 |
| 数据合规 | 15 万 | 6% | 基础监测 + 合规审查 |
| 项目管理 | 15 万 | 6% | 团队差旅 + 工具采购 |

适用场景：预算有限、需快速验证单一核心市场、团队精简。

### 4.3 中档 500 万（推荐，全年完整三支柱）

**定位**：推荐方案，覆盖权威+高频+纵深三支柱完整运转。

| 板块 | 预算 | 占比 | 核心动作 |
|------|------|------|----------|
| 央视 | 150 万 | 30% | 2 次专题片 + 4 次新闻报道 + 硬广配合 |
| 自媒体 | 130 万 | 26% | 15 位 KOC 签约 + 全矩阵运营 + 信息流投放 |
| 党媒 PR | 80 万 | 16% | 月度 3-4 篇 + 白皮书 + 圆桌论坛 |
| 学术推广 | 70 万 | 14% | 科室会 24 场 + 区域沙龙 6 场 + 全国会 1 场 |
| 数据合规 | 40 万 | 8% | 全链路监测 + 合规体系建设 + 舆情管理 |
| 项目管理 | 30 万 | 6% | 专职团队 + 季度复盘 + 工具平台 |

适用场景：已验证模型有效、需全国铺开、团队具备执行力。

### 4.4 上档 800 万（旗舰，抢占品类代名词）

**定位**：旗舰方案，目标是让品牌成为品类代名词。

| 板块 | 预算 | 占比 | 核心动作 |
|------|------|------|----------|
| 央视 | 250 万 | 31% | 3 次专题片 + 6 次新闻 + 年度冠名栏目 |
| 自媒体 | 200 万 | 25% | 30 位 KOC + 全平台矩阵 + 大规模投放 + IP 孵化 |
| 党媒 PR | 130 万 | 16% | 高频深度 + 行业白皮书 + 年度论坛主办 |
| 学术推广 | 120 万 | 15% | 科室会 48 场 + 区域 12 场 + 全国 2 场 + 海外会议 |
| 数据合规 | 60 万 | 8% | 数据中台 + AI 监测 + 全面合规审计 |
| 项目管理 | 40 万 | 5% | 专职团队扩编 + 月度复盘 + 外部顾问 |

适用场景：竞品已入场、需快速建立品类壁垒、预算充裕。

## 五、12 个月 Roadmap 模板

### Q1（M1-M3）：筛选 · 立项 · 谈判 · 起势

**M1 关键动作：**
1. 完成 KOL/KOC/种子候选池搭建（≥3 倍候选量）
2. 央视栏目立项接洽，确定合作框架
3. 自媒体矩阵账号注册/认证/基础内容填充

> GO/NO-GO：M1 末 — KOL 候选 ≥10 位初步沟通，央视制片方回复意向

**M2 关键动作：**
1. KOL Tier 1 首批签约（≥2 位）
2. 党媒合作方确定，首批选题策划
3. 数据监测体系搭建（基线数据采集）

> GO/NO-GO：M2 末 — 至少 2 位 KOL 签约，央视立项通过

**M3 关键动作：**
1. KOC Tier 2 首批签约（≥8 位），内容 SOP 下发
2. 自媒体首批内容上线（各号 ≥5 条）
3. 首场科室会/小型学术沙龙举办

> GO/NO-GO：M3 末 — 自媒体矩阵日常运转，首场学术活动完成

### Q2（M4-M6）：起量 · 首播 · 配稿 · 跑通

**M4 关键动作：**
1. 央视专题片拍摄（KOL 出镜 + 临床实录）
2. KOC 自媒体进入周更节奏，内容数据周报启动
3. 党媒首批深度稿件发布（≥3 篇）

**M5 关键动作：**
1. 央视专题片首播 + 全网二次分发
2. 首次节点战役（配合学术会议/健康日）
3. 种子医生 Tier 3 首批签约（≥15 位）

> GO/NO-GO：M5 末 — 央视首播完成，播后 7 天搜索指数涨幅 >50%

**M6 关键动作：**
1. 半年度数据复盘，调整下半年策略
2. KOL/KOC 季度评分首次执行
3. 全国学术会议卫星会筹备

### Q3（M7-M9）：放大 · 节点战役 · 矩阵

**M7 关键动作：**
1. 第二轮央视专题/新闻报道启动
2. 自媒体矩阵全面铺开（所有 KOC 进入稳定产出）
3. 区域学术沙龙密集举办（≥3 场/月）

**M8 关键动作：**
1. 年度核心节点战役执行（配合全国大会/医师节等）
2. 党媒+央视+自媒体三波段联动
3. 患者端内容开始释放（种子医生产出）

> GO/NO-GO：M8 末 — 品牌认知率调研 >40%，战役期间搜索峰值创新高

## 六、协同分工模板

### 6.1 现有合作方（长期日常）

| 模块 | 职责范围 |
|------|----------|
| IP 定位 | 医生个人品牌调性设计、视觉 VI、话术模板 |
| 账号搭建 | 各平台账号注册/认证/装修/基础运营 |
| 标准化科普 | 日常科普内容批量生产、排期发布、评论维护 |
| 数据基础报表 | 各平台数据抓取、基础周报/月报输出 |

**特点**：标准化程度高、流程成熟、成本可控、持续性强。

### 6.2 本方案（短期高峰+增量）

| 模块 | 职责范围 |
|------|----------|
| 央视立项 | 栏目对接/选题策划/拍摄协调/播出跟进 |
| 党媒深度 | 深度选题/采访协调/稿件撰写/发布推广 |
| 节点战役 | 大型战役策划/多渠道联动/资源调度/效果追踪 |
| 数据中台 | 全渠道数据整合/深度分析/策略建议/ROI 测算 |
| 合规法务 | 医疗广告合规审查/风险预警/法律文本支持 |

**特点**：资源门槛高、周期性强、需要行业关系和专业判断。

### 6.3 切口定义

> **他们做存量日常，我们做增量战役。**

- 存量日常：已建立的内容产出节奏和基础运营，不中断不替代
- 增量战役：在日常之上叠加的高峰动作——央视/党媒/学术/节点战役

边界清晰原则：
- 日常内容产出 → 现有合作方
- 重大节点内容 → 本方案统筹，现有方配合执行
- 数据基础报表 → 现有合作方
- 数据深度分析+策略建议 → 本方案

### 6.4 联席机制

| 机制 | 频率 | 参与方 | 内容 |
|------|------|--------|------|
| 周例会 | 每周一 | 双方项目经理+执行负责人 | 进度同步/问题暴露/下周计划 |
| 共享日历 | 实时 | 全员可见 | 内容排期/活动日期/审核节点/关键里程碑 |
| 窗口期协调 | 按需 | 项目总监级 | 重大节点前 2 周启动，协调资源/内容/时间冲突 |
| 季度复盘 | 每季度 | 双方管理层 | 阶段性成果/预算执行/下季度调整 |
