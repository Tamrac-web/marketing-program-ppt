# PPT 结构模板 · 医疗健康营销推广方案

## 设计规范

### 配色方案

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | `1E2761` | 深海军蓝，标题/深色背景页 |
| 辅色 | `CADCFC` | 冰蓝，正文/辅助文字 |
| 强调色 | `F96167` | 珊瑚红，数据高亮/关键指标 |
| 深色背景 | `0D1B2A` | 封面/战略页/金句页背景 |
| 浅色背景 | `F8F9FA` | 内容详情页背景 |
| 文字白 | `FFFFFF` | 深色背景上的文字 |
| 文字灰 | `8E99A4` | 注释/来源/页码 |

### 字体规范

| 元素 | 字体 | 大小 | 样式 |
|------|------|------|------|
| 页面标题 | Arial Black | 36-44pt | Bold |
| 章节标题 | Arial | 20-24pt | Bold |
| 正文 | Calibri | 14-16pt | Regular |
| 数据大字 | Georgia | 60-72pt | Bold |
| 注释/来源 | Calibri | 10-12pt | Regular, 灰色 |
| 英文副标题 | Calibri Light | 12-14pt | Italic |

### 布局原则

- 边距最小 0.5 英寸
- 内容块间距 0.3-0.5 英寸
- 深色页（封面/战略/金句）与浅色页（内容详情）交替使用
- 每页必须有视觉元素（数据卡片/图标/色块/分栏）
- 页码格式：`NN / 30`，右上角灰色小字

## 26 页结构

### Slide 01 · 封面
- **布局：** 全屏深色背景
- **内容：**
  - 公司名 · 内部提案（顶部小字）
  - 产品名 + 英文名（居中大标题）
  - 方案副标题（一句话核心策略）
  - 年份 + 交付说明（底部）
- **设计：** 深色背景 `0D1B2A`，标题白色，副标题冰蓝

### Slide 02 · 市场基本盘 (The Hook)
- **布局：** 左右双栏大数据对比
- **内容：**
  - 左栏：患者总量（大字数据 + 说明）
  - 右栏：认知率或覆盖率（大字数据 + 说明）
  - 底部：一句话总结反差 + 数据来源
- **设计：** 浅色背景，数据用珊瑚红 `F96167` 高亮

### Slide 03 · 企业基本盘 (Baseline)
- **布局：** 四象限网格
- **内容：**
  - 左上：技术代差（代际/专利/工艺）
  - 右上：临床验证（评分/数据/随访）
  - 左下：准入状态（医保编码/省份/定价）
  - 右下：合规体系（认证/冷链/质量体系）
- **设计：** 每象限用色块区分，带图标

### Slide 04 · 关键判断 (The Verdict)
- **布局：** 全屏深色 + 居中大文字
- **内容：**
  - 核心战略判断（3-5 行大字）
  - 支撑逻辑（底部小字 1-2 句）
- **设计：** 深色背景，文字白色，强调词用珊瑚红

### Slide 05 · 战略主张 (The Thesis)
- **布局：** 全屏深色 + 超大标题
- **内容：**
  - 一句话战略主张（中文 36pt+）
  - 英文翻译（底部 italic）
- **设计：** 与 Slide 04 呼应，极简视觉冲击

### Slide 06 · 目标受众分层
- **布局：** Before/After 双栏对比
- **内容：**
  - Before（传统打法）：问题点列表
  - After（本方案）：优势点列表
  - 底部：核心算式（如 "50 位 × 影响圈 ≈ 100 万级精准认知"）
- **设计：** 左栏灰色调（旧），右栏蓝色调（新）

### Slide 07 · 价值链路/漏斗 (The Funnel)
- **布局：** 横向 5 步流程图
- **内容：**
  - 5 个阶段节点（如：发声→同行可见→搜索→询问→转化）
  - 每步下方：关键动作 + 指标
- **设计：** 流程用箭头连接，每步用色块编号

### Slide 08 · 推广体系总览 (The System)
- **布局：** 三列并排
- **内容：**
  - 支柱一：名称 + 属性 + 3-4 个要点
  - 支柱二：名称 + 属性 + 3-4 个要点
  - 支柱三：名称 + 属性 + 3-4 个要点
  - 底部：三者关系总结
- **设计：** 每列顶部用不同色块标识

### Slide 09 · 支柱一详情 (Pillar I)
- **布局：** 章节引导页，深色背景
- **内容：**
  - 支柱名称（大标题）
  - 一句话定位
- **设计：** 全屏深色，过渡页

### Slide 10 · 支柱一 · 渠道组合
- **布局：** 三列 Tier 分级
- **内容：**
  - Tier 1 / Tier 2 / Tier 3 三档
  - 每档：频道/形式/目标人群/预期触达/预算
- **设计：** 浅色背景，三列等宽

### Slide 11 · 支柱一 · 内容形式
- **布局：** 三列内容类型
- **内容：**
  - A 类 / B 类 / C 类内容
  - 每类：时长/讲什么/样本选题 3 个
- **设计：** 浅色背景，列顶标注时长

### Slide 12 · 支柱二详情 (Pillar II)
- **布局：** 章节引导页，深色背景
- **内容：** 支柱名称 + 一句话定位

### Slide 13 · 支柱二 · 平台矩阵
- **布局：** 四列平台对比
- **内容：**
  - 每平台：权重/定位/主打选题/核心策略
- **设计：** 浅色背景，百分比用大字

### Slide 14 · 支柱二 · 内容工厂 SOP
- **布局：** 横向 5 步流程
- **内容：**
  - 选题库 → 拍摄 → 剪辑包装 → 分发 → 数据看板
  - 每步下方：关键约束/交付标准
- **设计：** 流程图+编号圆圈

### Slide 15 · 支柱三详情 (Pillar III)
- **布局：** 章节引导页，深色背景
- **内容：** 支柱名称 + 一句话定位

### Slide 16 · 支柱三 · 选题方向
- **布局：** 三列选题角度
- **内容：**
  - Angle A / B / C
  - 每个：主题/锚点/子选题 3-4 个/窗口期
- **设计：** 浅色背景

### Slide 17 · 协同分工
- **布局：** 左右双栏对比
- **内容：**
  - 左：现有合作方（长期日常）
  - 右：本方案（短期高峰+增量）
  - 底部：协作机制说明
- **设计：** 双栏用不同底色区分

### Slide 18 · 12 个月 Roadmap
- **布局：** 四列时间线（Q1-Q4）
- **内容：**
  - 每季度：3 个月的关键动作
  - 关键里程碑标注
- **设计：** 时间线用箭头串联，每 Q 用色块

### Slide 19 · 受众筛选模型
- **布局：** 左右分栏（评分+金字塔）
- **内容：**
  - 左：四维评分表
  - 右：三层金字塔图示
- **设计：** 金字塔用三种色深表示层级

### Slide 20 · 预算结构
- **布局：** 三列档位对比
- **内容：**
  - 下档 / 中档（推荐标★）/ 上档
  - 每档：总价 + 各项分配 + 适合场景
- **设计：** 中档列加强调色边框

### Slide 21 · KPI 体系
- **布局：** 四层漏斗（上→下）
- **内容：**
  - L1 曝光 / L2 认知 / L3 询问 / L4 转化
  - 每层：指标 + 目标值 + 归因方式
- **设计：** 漏斗形状色块，从宽到窄

### Slide 22 · 风险与合规
- **布局：** 四列风险卡片
- **内容：**
  - Risk 01-04：名称/法规依据/控制措施
- **设计：** 每张卡片带顶部色条

### Slide 23 · 核心金句 (The Takeaway)
- **布局：** 全屏深色 + 居中大文字
- **内容：**
  - 一句核心金句（中文）
  - 英文翻译（底部）
- **设计：** 极简，深色背景

### Slide 24 · Next Step (30/60/90 天)
- **布局：** 三列里程碑
- **内容：**
  - D-30 / D-60 / D-90
  - 每阶段 5 件具体事项
  - 交付物清单
- **设计：** 浅色背景，编号列表

### Slide 25 · 愿景 (The Vision)
- **布局：** 全屏深色 + 居中大文字
- **内容：**
  - 愿景描述（2-3 行）
  - 底部时间标注
- **设计：** 深色背景，文字白色

### Slide 26 · 致谢 (Thank You)
- **布局：** 全屏深色
- **内容：**
  - THANK YOU
  - 公司名 + 产品名 + 方案标题
  - End of Deck · 年份

## pptxgenjs 生成规范

### 全局设置

```javascript
const pptxgen = require("pptxgenjs");
let pres = new pptxgen();
pres.layout = "LAYOUT_16x9";
pres.author = "Marketing Program Generator";
pres.title = "{公司名}-{产品名}-营销推广方案";
```

### Slide Master 定义

```javascript
// 深色页 Master
pres.defineSlideMaster({
  title: "DARK_MASTER",
  background: { color: "0D1B2A" },
  objects: [
    { text: { text: "{slideNum} / 26", options: { x: 8.5, y: 5.2, w: 1, h: 0.3, fontSize: 10, color: "8E99A4" } } }
  ]
});

// 浅色页 Master
pres.defineSlideMaster({
  title: "LIGHT_MASTER",
  background: { color: "F8F9FA" },
  objects: [
    { text: { text: "{slideNum} / 26", options: { x: 8.5, y: 5.2, w: 1, h: 0.3, fontSize: 10, color: "8E99A4" } } }
  ]
});
```

### 常用布局模式

**大数据卡片：**
```javascript
slide.addText("1.5 亿", { x: 0.5, y: 1.5, w: 4, h: 1.5, fontSize: 72, fontFace: "Georgia", bold: true, color: "F96167" });
slide.addText("中国骨关节炎患者总量", { x: 0.5, y: 3, w: 4, h: 0.5, fontSize: 14, color: "8E99A4" });
```

**三列并排：**
```javascript
const colW = 2.8, startX = 0.5, gap = 0.3;
for (let i = 0; i < 3; i++) {
  const x = startX + i * (colW + gap);
  slide.addShape(pres.shapes.ROUNDED_RECTANGLE, { x, y: 1.2, w: colW, h: 3.8, fill: { color: "FFFFFF" }, shadow: { type: "outer", blur: 3, opacity: 0.1 } });
  slide.addText(titles[i], { x, y: 1.4, w: colW, h: 0.5, fontSize: 18, bold: true, align: "center", color: "1E2761" });
}
```

**横向流程图：**
```javascript
const steps = ["发声", "同行可见", "搜索", "询问", "转化"];
steps.forEach((step, i) => {
  const x = 0.5 + i * 1.9;
  slide.addShape(pres.shapes.OVAL, { x: x + 0.3, y: 1.5, w: 1.2, h: 1.2, fill: { color: "1E2761" } });
  slide.addText(`0${i+1}`, { x: x + 0.3, y: 1.5, w: 1.2, h: 1.2, fontSize: 20, color: "FFFFFF", align: "center", valign: "middle" });
  slide.addText(step, { x, y: 2.9, w: 1.8, h: 0.4, fontSize: 14, bold: true, align: "center", color: "1E2761" });
  if (i < steps.length - 1) {
    slide.addShape(pres.shapes.LINE, { x: x + 1.5, y: 2.1, w: 0.7, h: 0, line: { color: "CADCFC", width: 2 } });
  }
});
```
